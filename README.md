# 🏥 Healthcare Power BI Dashboard

## 📌 Project Overview

The Healthcare Power BI Dashboard is an interactive business intelligence project developed using Microsoft Power BI.

The dashboard provides insights into healthcare admissions, patients, doctors, hospitals, insurance providers, medical conditions, test results, medications, revenue, and billing information.

The project contains two interactive dashboard pages:

- Overview
- Financial Analysis

---

## 🎯 Objectives

- Analyze healthcare admission trends over the years
- Understand patient demographics
- Analyze admission types
- Monitor revenue and billing amounts
- Identify major insurance providers
- Analyze doctors based on billing and revenue
- Understand patient distribution by medical condition
- Analyze patients by blood type and medication
- Provide interactive filtering for better decision-making

---

## 📊 Dashboard Pages

### 1. Overview Dashboard

The Overview dashboard provides insights into:

- Total Revenue
- Total Admissions
- Total Hospitals
- Total Doctors
- Gender Distribution
- Admission Type Distribution
- Test Results
- Age Bucket Distribution
- Admission Trend Year-over-Year
- Patients by Blood Type
- Patients by Medical Condition
- Patients by Insurance Provider
- Patients by Medication

![Overview Dashboard](Dashboard/Overview.png)

---

### 2. Financial Analysis Dashboard

The Financial Analysis dashboard focuses on financial and billing-related insights.

It includes:

- Top 5 Insurance Providers by Billing Amount
- Top 5 Doctors by Billing Amount
- Admission Trend Year-over-Year
- Top 5 Doctors by Revenue and Patient Count
- Doctor, Hospital, and Insurance Provider filters

![Financial Analysis Dashboard](Dashboard/Financial_Analysis.png)
